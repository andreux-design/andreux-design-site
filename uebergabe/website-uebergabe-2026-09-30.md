## 2. Kampagnen-Karte (KI-gestützte Systeme), ganz ersetzen

Überschrift, bisher „Ein System für ganze Werbekampagnen" / „A system for
entire advertising campaigns". Folgt dem Text (Faktenprüfer: Werbekampagnen ist
Hochstufung): **„Ein System für ganze Funnels" / „A system for entire funnels"**.
Die Überschrift steht nicht in `texte/website.md`; das ist eine Lücke im
Prüfweg.

DE, Absatz 1: Auf diesen Regeln steht heute ein mit Claude Code gebautes System,
das ganze Funnels produziert. Für einen Kunden wird ein Briefing hinterlegt, und
daraus baut das System eine Seite mit passenden Sektionen und Text. Sichtbar
wird sie in einem Wizard, den ich entworfen und gebaut habe. Damit soll jeder im
Team mit wenigen Klicks eine Landingpage erzeugen können. Links stehen die Texte
als Formular, rechts steht die Vorschau der Seite, umschaltbar auf die mobile
Ansicht. Wer mehr Mühe hineinstecken will, kann Sektionen hinzufügen, entfernen
oder verschieben. Das allgemeine Layout ist durch ein Template festgelegt.
Accessibility ist Bedingung für die Freigabe, nicht Nacharbeit.

DE, Absatz 2: Von Hand brauchte nach meiner Erinnerung allein der erste Aufbau
einer Seite einen halben bis einen ganzen Tag, ohne Text und ohne mobile
Fassung. Mit dem Wizard steht die erste Fassung mit Text nach rund fünf Minuten,
Korrekturen kommen obendrauf. Der Wizard ist fertig gebaut und läuft noch lokal
bei mir, die Übernahme ins gemeinsame System steht aus.

DE, Absatz 3: Die Rechte liegen beim Arbeitgeber, zeigen kann ich davon also
nichts.

EN, paragraph 1: On these rules now stands a system built with Claude Code that
produces entire funnels. For a client, a briefing is stored, and from it the
system builds a page with suitable sections and text. It becomes visible in a
wizard that I designed and built. The idea is that anyone on the team can create
a landing page with a few clicks. The texts are on the left as a form, the
preview of the page on the right, switchable to the mobile view. Anyone who
wants to put in more effort can add, remove or move sections. The overall
layout is set by a template. Accessibility is a condition for approval, not
rework.

EN, paragraph 2: By hand, as I remember it, the first build of a page alone
took half a day to a full day, without text and without the mobile version.
With the wizard, the first version, text included, is ready after about five
minutes, and corrections come on top. The wizard is finished but still runs
locally on my machine, and the move into the shared system is pending.

EN, paragraph 3: The rights belong to my employer, so I can't show any of it.
