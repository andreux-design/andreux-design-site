## About me

I am currently the only product designer responsible for an agency's entire production: design, copy and system. I take a product from research through concept to implementation. Along the way I notice where work repeats, and I build the system for it out of components, tokens and rules. I was already doing this more than ten years ago, with an input form I built for a recurring report that was then ready at the push of a button. Later it was design systems in Figma; today it is systems built with AI.

In my work, a criterion decides whether a design is good, not taste. In code, compilers and tests tell you whether something is right. For design and copy there is no compiler, so someone who knows the craft has to write the rules.

## End-to-end product design

Research, concept, prototype, handover to development, support through to launch.

### GoTiger App

#### Delivery service for Asian groceries

GoTiger delivered Asian groceries in Berlin, and I designed the app for the service. One problem lay outside the app. Without prior knowledge, you don't know what you could actually buy in an Asian supermarket. So every product detail page explained the product, and recipes added the ingredients to the basket with one tap, scaled to the number of servings. You deselected whatever you already had at home. There was also a swipe game for finding the right recipe. All of it went live.

I started with a survey of target users and followed it up later with user tests in interviews. When a colleague left, I took over her tasks as well and briefed the external development team from then on.

### The “one conference” app

#### Redesigned for mobile and desktop

In 2024, at a digital agency in Munich, I redesigned the internal conference app “one conference” for mobile and desktop and added features. To do that, I built a Figma prototype with tokens and variables, so the flows ran inside the prototype itself, and handed it over to the in-house developers. My version ran at the annual conference.

## Design systems

I build design systems, from design tokens through several layers to nested components and flows, using Figma's own features.

### Two systems on my own initiative

#### A token-based design system, an internal library

Both were created in 2024 at the Munich agency.

The first is a design system built from design tokens. Setting up a new brand took a lot of effort at the agency, and the white-label system we used to build client projects was spread across several files. So I built a system meant to solve this problem. The token system can be switched to other brands in a few clicks and includes light and dark mode. I used a demo library to show the effects; it stayed with the agency.

The second is an internal library. For Volkswagen Commercial Vehicles I built the websites of two models, the ID. Buzz and the California. The manufacturer had documented its UI components, but our team did not have them in Figma. I gradually built the library in Figma so that we would not have to recreate them every time.

## AI-assisted systems

### A library of building blocks for automated pages

#### Layouts that became building blocks

At my current agency my responsibilities include landing pages, with concept, design and copy. I began there by building page layouts by hand and writing my own rules for copy and design as the basis for evaluation. Back then I set up a small design system in Figma for each client so that I could design consistently myself. Those layouts have become building blocks, and pages are now generated from them automatically. If a client has no design system yet, or only an inadequate one, a new one is created at the start of the project following a set of rules and applied to the building blocks. What I had built by hand as layouts has become the basis of automated production.

### One interface from brief to launch

#### Account managers can set up landing pages themselves

Changes used to go through me, and time was lost in the back and forth between brief, feedback and adjustment. That is why I used Claude Code, an AI tool, to design and build an interface in which an account manager can set up, create and adjust a landing page on their own, all the way to hosting and tracking. The idea is that even someone with no prior knowledge can set up and adjust a page without breaking anything. Since early November 2026 the interface has been live in the agency's internal system and is in use. I can't show the interface itself; the rights to it belong to my employer.

## From university

### filo

#### Messages and files in one place

filo, my bachelor's thesis, came out of everyday work. You look for a message about a project and can't remember where it was. I wanted an interface that brings everything together in one place without everyone having to use the same tool. I built the interface as a clickable Figma prototype that simulates its states with 271 variables and no backend. I evaluated the prototype with 23 participants in moderated online sessions. Participants with little technical experience managed it too.
